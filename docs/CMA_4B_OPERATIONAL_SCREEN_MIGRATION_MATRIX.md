## Summary

- **5 occurrences migrated** (Outbound Campaigns stat strip ×2 measures, Campaign Detail ×3 measures) — all verified byte-identical against production before implementation.
- **2 real candidates found but deliberately deferred** (Agent Detail sentiment/intent confidence) — population mismatch confirmed in code, needs a hook rebuild, not safe to wire up as-is.
- **9 QA measures: none migrated** — confirmed population mismatch (Human-only UI vs. combined-population CMA RPC), and no alternative UI occurrence exists to redirect to instead.
- **1 chat measure, 1 action measure**: no existing UI occurrence found anywhere in the app to migrate.
- **3 interaction measures (FCR/ESC/AHT) and their Call Logs occurrences**: untouched, pending business definitions.
- Everything else inspected (Live View, Action Required, Automated QA Inspector, Human QA Review, individual call/target records) is operational record-management or real-time status, correctly left as class D.
